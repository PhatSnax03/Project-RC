# Project RC

Foundation for the Codex CRM built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) to view the app.

## Project Structure
- `app/`: App Router pages, including global layout and styles.
- `components/`: Shared UI components.
- `public/`: Static assets.
- `tailwind.config.ts`: Tailwind CSS configuration.
- `tsconfig.json`: TypeScript configuration with `@/*` alias to the project root.
